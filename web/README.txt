Eleosynth — web version
=======================
Open eleosynth.html in Chrome or Edge to play right away.

For guitar input and MIDI the browser needs the page served from a web address. Double-click:
  Windows:      Start-Eleosynth-Windows.bat
  Mac / Linux:  start-eleosynth-mac-linux.command   (or run: python3 serve.py)
Python 3 is required. It opens http://localhost:8752/eleosynth.html and only listens on this computer.
